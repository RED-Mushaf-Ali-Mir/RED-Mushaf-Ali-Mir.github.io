Convolutions without the mystery

The operation, tensor shapes, and design choices behind the first CNN functions I implemented.

21 August 20268 min readLearning source: Andrew Ng, Deep Learning Specialization

Why not flatten the image?

A fully connected layer ignores two useful facts about images: nearby pixels are related, and the same pattern may appear anywhere. A convolution preserves spatial structure and reuses the same small set of weights across positions. That weight sharing reduces parameters and gives the layer translation-aware feature detection.

What one filter computes

A filter spans the full input depth but only a small height and width. At one position, the layer multiplies the filter and image slice element by element, sums the result, adds a bias, and produces one number. Sliding the filter across the image produces one activation map.

Z[i,j,k] = Σ(Aslice · Wk) + bk

Different filters learn different patterns. Early layers may respond to edges or color changes; deeper layers combine those activations into larger structures.

Padding and stride change the geometry

  • Padding adds pixels around the border. “Same” padding can preserve height and width and gives border pixels more opportunities to participate.
  • Stride controls how far the filter moves. A larger stride downsamples by evaluating fewer positions.
  • Filter size controls the local window examined at one layer.
nout = ⌊(n + 2p − f) / s⌋ + 1

This output-size equation became my fastest correctness check. If the allocated tensor disagreed with it, a loop boundary or padding assumption was wrong.

The forward pass I implemented

for i in range(batch_size):
    padded = zero_pad(A_prev[i], pad)
    for h in range(n_H):
        v0, v1 = h * stride, h * stride + f
        for w in range(n_W):
            h0, h1 = w * stride, w * stride + f
            for c in range(n_C):
                window = padded[v0:v1, h0:h1, :]
                Z[i, h, w, c] = np.sum(window * W[..., c]) + b[..., c]

The nested loops are not how a production framework executes convolution, but writing them made every axis explicit: example, vertical position, horizontal position, and output channel.

Pooling and receptive fields

Max pooling keeps the strongest activation in each window; average pooling keeps the mean. Both reduce spatial size without learned weights. Pooling can add local invariance, although modern architectures sometimes use strided convolutions instead.

A neuron’s receptive field is the region of the original image that can affect it. Stacking small filters grows that field while inserting nonlinearities between stages. This is how deeper layers gain wider context without requiring one enormous filter.

The core intuitionA CNN is not “looking at an image” all at once. It builds a hierarchy by repeatedly asking which local patterns are present and how those patterns combine.
