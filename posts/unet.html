U-Net: keeping detail while learning context

Semantic segmentation needs both a broad understanding of the scene and exact pixel locations. U-Net is designed to preserve both.

12 September 20267 min readLearning source: Andrew Ng, Deep Learning Specialization

Classification, detection, segmentation

Classification returns one label for an image. Detection returns labeled boxes. Semantic segmentation assigns a class to every pixel, producing an output mask with the same spatial resolution as the input.

Downsampling is useful because it expands the effective receptive field and builds semantic context, but it removes location detail. U-Net resolves that tension with a contracting encoder and an expanding decoder.

The contracting path

Each encoder block applies repeated convolutions, then usually max pooling. As height and width shrink, channel depth grows. I designed each block to return two values: the activation before pooling for a future skip connection, and the pooled activation for the next block.

def conv_block(x, n_filters, dropout=0, max_pool=True):
    conv = Conv2D(n_filters, 3, activation="relu", padding="same")(x)
    conv = Conv2D(n_filters, 3, activation="relu", padding="same")(conv)
    if dropout:
        conv = Dropout(dropout)(conv)
    next_layer = MaxPool2D(2)(conv) if max_pool else conv
    return next_layer, conv

The expanding path

The decoder upsamples the low-resolution representation, concatenates it with the matching encoder activation, and refines the combined tensor with convolutions. The skip connection supplies crisp spatial features that pooling would otherwise erase.

up = Conv2DTranspose(n_filters, 3, strides=2, padding="same")(x)
merge = concatenate([up, encoder_skip], axis=3)
x = Conv2D(n_filters, 3, activation="relu", padding="same")(merge)
x = Conv2D(n_filters, 3, activation="relu", padding="same")(x)

This is different from a residual addition. U-Net concatenates feature maps, so the next convolution can decide how to mix encoder detail with decoder context. Concatenation also increases the channel dimension, which must be tracked carefully.

The final prediction

A 1×1 convolution maps the decoder features at every pixel to n_classes logits. Softmax can turn those logits into a per-pixel class distribution; the winning class produces the segmentation mask.

output shape = (batch, height, width, classes)

What I checked while implementing

  • Every upsampled tensor had the same height and width as its matching skip tensor.
  • The number of filters doubled down the encoder and halved up the decoder.
  • The bottleneck block did not pool again.
  • The final layer returned class logits rather than a hidden feature depth.
The architectural lessonCompression builds meaning; high-resolution skips restore position. U-Net works because it does not force one representation to do both jobs alone.
