YOLO, IoU, and non-max suppression

The network produces dense box predictions. The pipeline turns them into a small, meaningful set of detections.

05 September 20269 min readLearning source: Andrew Ng, Deep Learning Specialization

Detection asks two questions

Classification asks what is in an image. Detection must also answer where each object is, and the number of objects is not fixed. YOLO handles this in one network pass by predicting many candidate boxes across a spatial grid.

Each candidate contains box geometry, an objectness confidence, and class probabilities. Post-processing then converts the dense output into final boxes.

From center boxes to corners

Models commonly represent a box by center (bₓ, bᵧ), width bᵥ, and height bₕ. Drawing and overlap calculations are easier with corners:

x₁=bₓ−bᵥ/2, y₁=bᵧ−bₕ/2, x₂=bₓ+bᵥ/2, y₂=bᵧ+bₕ/2

Confidence filtering

A class-specific score combines the probability that an object exists with the conditional class probability. For each candidate, I keep the strongest class and discard the box if that score falls below a threshold.

box_scores = box_confidence * box_class_probs
box_classes = tf.argmax(box_scores, axis=-1)
box_class_scores = tf.reduce_max(box_scores, axis=-1)
mask = box_class_scores >= threshold

This removes obvious background predictions, but several high-scoring boxes can still describe the same object.

Intersection over Union

IoU measures how much two rectangles agree. First compute the intersection rectangle. Then divide its area by the union of both boxes.

IoU(A,B) = area(A ∩ B) / area(A ∪ B)

An IoU of zero means no overlap; one means identical boxes. The max(0, …) terms matter because non-overlapping corners otherwise create a negative width or height.

inter_w = max(0, min(a.x2, b.x2) - max(a.x1, b.x1))
inter_h = max(0, min(a.y2, b.y2) - max(a.y1, b.y1))
intersection = inter_w * inter_h
union = area(a) + area(b) - intersection
iou = intersection / union

Non-max suppression

  1. Choose the remaining box with the highest class score.
  2. Keep it as a final detection.
  3. Suppress lower-scoring boxes of the same class whose IoU with it exceeds the threshold.
  4. Repeat with the boxes that remain.

Class-aware suppression is important. A person box and a bicycle box may overlap heavily and both be correct; they should not eliminate each other only because their coordinates overlap.

Thresholds are trade-offs

A high score threshold improves precision but may miss objects. A low threshold keeps recall but creates more false positives. Likewise, a low IoU threshold suppresses aggressively; a high one may leave duplicate boxes. These values are part of inference behavior and should match the application and evaluation metric.

What changed my understandingObject detection is not only a CNN architecture. Coordinate conventions, broadcasting, filtering, overlap geometry, and suppression are part of the model system that users actually see.
