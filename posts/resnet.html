Why residual connections help deep networks

ResNet reframes a block’s job: learn a useful change to the input instead of rebuilding the entire transformation.

29 August 20267 min readLearning source: Andrew Ng, Deep Learning Specialization

Deeper is not automatically better

More layers should give a network more representational capacity, yet very deep plain networks can show a degradation problem: training error becomes worse as layers are added. This is not only overfitting. Optimization itself becomes difficult, and gradients have a long path through repeated transformations.

The residual idea

A residual block sends the input along a shortcut and adds it to the learned path:

a[l+2] = ReLU(F(a[l]) + a[l])

If the best transformation is close to the identity, the residual branch only needs to learn a small correction. Setting its weights near zero leaves a clean identity route, so adding a block does not have to make the existing representation worse.

Identity block

An identity block keeps spatial dimensions and channel depth unchanged. The shortcut therefore needs no learned parameters.

X_shortcut = X
X = Conv2D(F1, 1, strides=1)(X)
X = BatchNormalization(axis=3)(X)
X = Activation("relu")(X)

X = Conv2D(F2, f, padding="same")(X)
X = BatchNormalization(axis=3)(X)
X = Activation("relu")(X)

X = Conv2D(F3, 1)(X)
X = BatchNormalization(axis=3)(X)
X = Add()([X, X_shortcut])
X = Activation("relu")(X)

The important implementation detail is that the final activation happens after addition. The branch learns F(X); the block then combines it with the unchanged input.

Projection block

When the main path changes resolution or channels, direct addition is impossible because tensor shapes differ. A projection shortcut uses a 1×1 convolution, often with the same stride as the main path, to produce a compatible shape.

A reliable debugging ruleBefore an element-wise addition, write down both tensor shapes. Most residual-block mistakes are not conceptual—they are mismatched height, width, or channel depth.

How ResNet-50 is organized

ResNet-50 uses bottleneck blocks: a 1×1 convolution reduces channels, a 3×3 convolution processes spatial features, and another 1×1 convolution expands channels. Stages begin with a projection block when resolution changes, followed by identity blocks.

The architecture is still a CNN, but the shortcuts change the optimization landscape. They provide direct information and gradient routes across many layers, making depth practical rather than merely possible on paper.
